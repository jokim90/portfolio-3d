# Jungrun Kim — 3D Career Portfolio

Single-page portfolio with a WebGL globe (Three.js r128) showing content-export routes from Seoul to 29 markets.

- `index.html` — the site (fonts from Google Fonts, Three.js from cdnjs). Written in English; Korean strings live in the `KO` dictionary in the script at the end of the file and are swapped in by the EN / KO toggle.
- `ryoony/` — the Ryoony interview-agent widget.
- `images/work/korean-doctors/` — screenshots for Case 02 (Korean Doctors).
- This repo mirrors `jokim90/jokim90.github.io`; edit there first, then copy the same files here.
- Deployed with GitHub Pages from the `main` branch root.

Live: https://jokim90.github.io/portfolio-3d/
