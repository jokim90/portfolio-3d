# Jungrun Kim — 3D Career Portfolio

Single-page portfolio with a WebGL globe (Three.js r128) showing content-export routes from Seoul to 29 markets.

- `index.html` — the whole site (self-contained; fonts from Google Fonts, Three.js from cdnjs)
- Deployed with GitHub Pages from the `main` branch root.
